# دليل بوابات الجودة والاختبار قبل الإصدار (Release Gates)

يحدد هذا الدليل الإجراءات الإلزامية التي يجب اجتيازها بالكامل قبل السماح بنشر أي إصدار لمنصة **CodeQ** إلى بيئة الإنتاج أو مستودع GitHub.

---

## 2. أوامر التشغيل والتحقق محلياً

قبل تنفيذ أي عملية `git commit` أو `git push`:

1. **تشغيل الاختبارات الإلزامية:**
   ```bash
   npm run test
   ```
   *يجب أن تنتهي كافة الاختبارات بنتيجة 0 Failures.*

2. **بناء حزمة الإنتاج:**
   ```bash
   npm run build
   ```
   *يجب أن يتولد مجلد `dist/` ويحتوي على `.nojekyll` و `404.html` و `index.html` و `assets/`.*

3. **معاينة حزمة الإنتاج محلياً:**
   ```bash
   npm run preview
   ```
   *فتح الرابط واختبار إرسال سؤال برمجي حقيقي ومراجعة تنسيق الأكواد وأزرار النسخ.*

---

## 3. أتمتة البوابات في GitHub Actions

داخل خط أنابيب النشر (`.github/workflows/deploy.yml`):
- مرحلة `build-and-test` تُنفذ خطوة `npm run test` قبل خطوة البناء والنشر.
- في حال فشل أي اختبار إلزامي، تتوقف عملية الـ CI فوراً، ويتم حجب أي تحديث لفرع `gh-pages` أو نشر لبيئة `github-pages`.
- مرحلة `deploy` مشروطة بنجاح كامل مرحلة الفحص عبر `needs: build-and-test`.
