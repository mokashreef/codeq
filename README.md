## 🌟 أبرز المميزات

1. **ذكاء اصطناعي حقيقي دون مفاتيح API (Zero-Key AI):**
   - **تشغيل محلي في المتصفح (WebLLM عبر WebGPU):** تعمل نماذج مثل `SmolLM2 (360M)`, `Llama 3.2 (1B)`, و `Qwen 2.5 Coder (1.5B)` داخل متصفح المستخدم مباشرة باستخدام كرت الشاشة، مع الحفاظ على سرية الكود تماماً والعمل حتى بدون إنترنت بعد التحميل الأول.
   - **مزود سحابي مجاني فوري (Puter.js):** إمكانية الاستعانة فورياً بنماذج رائدة مثل `GPT-4o mini` و `Claude 3.5 Sonnet` و `DeepSeek V3` دون الحاجة لأي مفتاح أو تسجيل أو دفع مالي.
   - **خيار اختياري للمطورين (BYOK):** إمكانية إدخال مفتاح API خاص للمستخدمين المتقدمين وحفظه في المتصفح فقط دون إرساله لأي جهة.

2. **واجهة عربية أصيلة وعصرية (RTL-First):**
   - تصميم حديث ومتقن يدعم الوضعين الداكن والفاتح تلقائياً.
   - طباعة عربية راقية باستخدام خط `IBM Plex Sans Arabic` وأكواد بخط `JetBrains Mono`.
   - محرر أسئلة يدعم اختيار لغات البرمجة (JavaScript, Python, C++, Java, Go, Rust, SQL, وغيرها) واختصار الإرسال `Ctrl + Enter`.

3. **استعراض وتنسيق الأكواد البرمجية (Code Engine):**
   - دعم كامل لصيغة Markdown والجداول والقوائم.
   - تلوين الصياغة (Syntax Highlighting) لجميع اللغات.
   - زر مستقل لنسخ كل كتلة كود بنقرة واحدة، مع زر لنسخ كامل الإجابة.

4. **إدارة المحادثات محلياً (Local-First Persistence):**
   - حفظ المحادثات والسجل كاملاً في متصفح المستخدم باستخدام `IndexedDB` و `LocalStorage`.
   - دعم الجلسات المتعددة ومتابعة الحوارات في نفس الموضوع.
   - بحث لحظي داخل المحادثات السابقة.
   - تبويب خاص لحفظ الأسئلة والإجابات في المفضلة.
   - تصدير السجل بصيغة JSON واستيراده بسهولة.

5. **فحص العتاد وتوافق الجهاز:**
   - فحص آلي فوري لدعم المتصفح لتقنية `WebGPU` وتقدير ذاكرة كرت الشاشة والتوصية بالنموذج الأنسب.

## 📊 مقارنة بين الإصدار القديم والإصدار الجديد Rebuilt

| المعيار | الإصدار القديم (Legacy v1) | الإصدار الجديد (CodeQ v2 Rebuilt) |
| :--- | :--- | :--- |
| **محرك الذكاء الاصطناعي** | إجابات وهمية (Mock Data) محفوظة مسبقاً | نماذج ذكاء اصطناعي حقيقية بالكامل (WebLLM + Puter.js) |
| **مفاتيح الـ API** | تسريب مفتاح خاص في `.env` | **صفر مفاتيح مطلوبة** من المستخدم أو المطور، مع حماية أمنية صارمة |
| **استضافة GitHub Pages** | غير مدعومة (اعتمدت على Express و MongoDB محلياً) | **مدعومة بالكامل 100%** عبر معمارية Static / Local-First |
| **الأتمتة و CI/CD** | لا يوجد أي Workflow | أتمتة كاملة عبر **GitHub Actions** مع فحص واختبارات وبناء تلقائي |
| **حفظ البيانات** | مصفوفات ذاكرة تفقد بياناتها مع كل إغلاق | تخزين محلي دائم عبر `IndexedDB` مع دعم التصدير والاستيراد |
| **استعراض الأكواد** | تعبيرات Regex بدائية ونسخ يدوي | مكتبة `Marked` + `Highlight.js` مع أزرار نسخ فورية لكل كتلة كود |
| **التوافق مع الأجهزة** | محلي فقط على `localhost:3000` | متجاوب مع الهواتف والأجهزة اللوحية والحواسيب |

## 💻 التشغيل المحلي والتطوير

### المتطلبات الأساسية
- **Node.js** إصدار 18 أو أحدث (يُفضل 20+)
- **npm** أو **pnpm** أو **yarn**

### خطوات التشغيل:

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/mokashreef/codeq.git
   cd codeq
   ```

2. **تثبيت الحزم البرمجية:**
   ```bash
   npm install
   ```

3. **تشغيل بيئة التطوير المحلية:**
   ```bash
   npm run dev
   ```
   افتح الرابط `http://localhost:5173/` في متصفحك.

4. **تشغيل الاختبارات الآلية (Automated Tests):**
   ```bash
   npm run test
   ```

5. **بناء نسخة الإنتاج (Production Build):**
   ```bash
   npm run build
   ```

6. **معاينة نسخة الإنتاج محلياً:**
   ```bash
   npm run preview
   ```

## 🔒 الأمان والخصوصية

- **لا نجمع أي بيانات:** كافة الأكواد والأسئلة والمحادثات تُعالج إما محلياً على جهازك أو عبر اتصال مجهول، وتُخزن فقط في متصفحك.
- **لا توجد مفاتيح مسربة:** تم فحص المشروع والتأكد من خلوه التام من أي مفاتيح مسربة أو أسرار، مع إضافة سياسة استبعاد صارمة في `.gitignore`.
- **مفتوح المصدر بالكامل:** الكود متاح للجميع للمراجعة والتدقيق والتطوير.
