# CodeQ - منصة الأسئلة البرمجية بالذكاء الاصطناعي

منصة ويب تتيح للمستخدمين طرح أسئلة برمجية والحصول على إجابات فورية باستخدام الذكاء الاصطناعي.

## المميزات

- 🚀 طرح أسئلة برمجية والحصول على إجابات فورية
- 🤖 مدعوم بالذكاء الاصطناعي (OpenAI/Gemini)
- 💾 حفظ الأسئلة والإجابات المفضلة
- 🌙 وضع داكن/فاتح
- 📱 تصميم متجاوب مع جميع الأجهزة
- 🔒 نظام مستخدمين آمن
- 📊 أسئلة شائعة ومجتمع

## التقنيات المستخدمة

### Frontend
- HTML5, CSS3, JavaScript (ES6+)
- Highlight.js for code syntax highlighting
- Font Awesome for icons

### Backend
- Node.js with Express
- MongoDB for database
- JWT for authentication
- Integration with AI APIs

## كيفية التشغيل محلياً

### المتطلبات الأساسية
- Node.js 16+
- MongoDB
- npm أو yarn
